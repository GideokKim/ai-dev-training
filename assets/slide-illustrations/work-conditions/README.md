# Work condition icons

S100, S101 and S103–S106 use FolderOpen, ListChecks, Wrench, Bot,
FileText, UserRound, Target, Route, ListTree, UsersRound, ShieldCheck,
Unplug and Undo2 from
[Lucide 1.8.0](https://lucide.dev). Each transparent PNG preserves the
upstream paths with a 1.75-unit stroke on the original 24-unit grid,
rendered at 360 × 360. The source slide sets their final size and role.
