# Loop role icons

S82 uses Clock, GitBranch, ListChecks, Plug, UsersRound and Notebook from
[Lucide 1.8.0](https://lucide.dev/). The PNGs preserve the upstream paths
and rounded terminals. Each is rendered on a transparent 360 × 360 canvas
with a 1.75-unit stroke on the original 24-unit grid. Colors follow the six
roles in the slide source. Each file is embedded as one picture in the deck.

The [upstream license](LICENSE) includes the Lucide and Feather notices.
