# S11 Resource Growth Graph Images

Decision: DEC-0040. Date: 2026-10-21 (Asia/Seoul).

## Assets and Use

- Method: built-in imagegen, transparent RGBA PNGs. Original generated files were copied unchanged into this repository.
- Token curve: `S11-token-growth.png`.
- Time curve: `S11-time-growth.png`.
- Both replace S11's former native curve/arrow objects. Labels remain editable native text in their original positions. All other slide content and the footer boundary remain unchanged.
- These are qualitative teaching illustrations with no data axes, units, numeric values, rates or measured exponential law. They do not represent a new Trial, actual cost measurement, Agent failure or guaranteed resource increase.

## Exact Prompt — Token Curve

Use case: infographic-diagram. Asset type: transparent raster curve illustration for a Korean engineering training PowerPoint. Create one single smooth, strongly rising warm-ochre curve with an integrated arrowhead. It starts almost horizontal at lower left, then bends gradually and sweeps steeply upward toward upper right. The shape is a polished editorial image, with a restrained amber-to-dark-ochre color treatment (#805400 and warm gold), subtle depth and clean edges. Wide landscape composition about 3:1; curve fills the canvas with only 5% clear transparent padding; keep all of the arrowhead inside. Transparent background, no white rectangle. Absolutely no text, letters, digits, scales, axes, grids, tick marks, data points, legends, icons, coins, clock, logos or watermark. Just the curved upward arrow. It illustrates qualitatively that further exploration/retrying may consume more tokens; it does NOT represent measured data or an exponential law. It must remain crisp and simple when displayed about 250 pixels wide by 95 pixels high. Do not add decorative objects.

## Exact Prompt — Time Curve

Use case: infographic-diagram. Asset type: transparent raster curve illustration for a Korean engineering training PowerPoint, paired stylistically with another warm-ochre rising curve. Create one single smooth curved upward arrow, almost flat through its first half, then increasingly steep toward its upper-right integrated arrowhead. Use a polished editorial rendering with restrained amber-to-dark-ochre color treatment (#805400 and warm gold), subtle depth and clean edges. Wide landscape composition about 3:1; curve fills the canvas with only 5% clear transparent padding; keep its complete arrowhead inside. Transparent background, no white rectangle. Absolutely no text, letters, digits, axes, tick marks, grids, scales, numeric data, data points, legends, clock, token icons, logos or watermark. Just the curved upward arrow. This is a qualitative teaching metaphor for potentially longer work time, with no measured rate, duration or exponential-law claim. It must be crisp and simple at about 250 pixels wide by 95 pixels high. Do not add decorative objects.
