가는 선과 별도 rightArrow 도형이 만나는 부분에서 굵기가 달랐다. 하단의 두 연결을
같은2px 선·삼각 화살촉의 Native PowerPoint connector로 바꿨다. 중심 높이와 시작/끝 위치를
유지하고 글자·단계·프롬프트·코드·Notes·근거를 변경하지 않았다.120장·420분은 그대로다.

Full과 ACT0의 S04 slide XML만 변경했으며 나머지 모든 package part와 Notes는
바이트가 같다. 미디어·표·차트·워크북·Theme/Layout도 유지한다. source factory에서도
같은 connector가 생성되며 최종 S04와 픽셀이 같다.

최종 Full120장과 ACT0 15장을 재입력해 PNG135개를 렌더링했다. 다른119장 Full 화면은
기존과 픽셀이 같고 S04도 두 화살표 영역 밖은 같다. Full/ACT0 15개 화면은 모두 같다.
수정된 S04를 개별 크기로 검토했으며 새 잘림·겹침을 발견하지 않았다. 다른5개 ACT
PPTX와 Markdown Notes는 변경하지 않았다. 파일 정보·전체/ACT0 montage만 정렬했다.

Windows PowerPoint·발표 환경·리허설은 기존 미검증 상태다. 제품 사실·성과·Claim을
추가하지 않았다. Demo 저장소·웹·발표 묶음은 변경하지 않는다.
