# S83 · 목표에서 인계까지, 루프의 8단계

## 현재 화면 · DEC-0157

단계·활동·산출물을 늘어놓던 화면을 준비 → 구현·검토 반복 → 사람에게 인계의 흐름도로 바꿨다. 판단(⑦)에서 보완이 필요하면 구현(④)으로 돌아가는 경로가 중앙에 보인다. 완료하거나 중단하면 오른쪽의 결과 인계(⑧)로 간다. 완료 시에는 검증 결과, 중단 시에는 남은 일을 넘긴다. 전체 단계 설명과 산출물은 [S83 발표 Notes](../notes/ACT_4_NOTES.md#s83--목표에서-인계까지-루프의-8단계)에서 확인할 수 있다.

기준판 `277ccc5`와 통합 113장·ACT4 20장의 렌더를 대조했다. S83 이외의 112개 화면이 같고, 두 PPT에서 S83의 그림이 동일하다. 단계 번호와 분기, 도형 정렬, S82·S84 연결, 19개 필드의 내장 Notes를 확인했다. S83의 강의 1분·사례 4분과 전체 389분을 유지했다. Windows 발표 PC와 교육장 투사는 미검증이다.

## 이전 판본 · DEC-0155

DEC-0155에 따라 사용자가 지정한 여덟 단계의 이름·활동·산출물을 같은 순서로 정리했다. 화면은 단계 번호와 흐름선, 각 단계의 활동·결과, 7단계에서 4단계로 돌아가는 보완 경로로 구성된다. 준비 단계의 워크트리·서브에이전트는 필요한 경우에 사용한다. 5단계는 실행으로 근거를 얻고, 6단계는 별도 관점에서 의견과 남은 문제를 기록한다. 7단계에서 완료 또는 중단하면 8단계에서 결과를 인계한다. 중단할 때는 미실행 항목과 후속 작업을 남겨 사람이 판단할 수 있도록 한다.

원문의 자세한 설명은 S83 발표 Notes에 있다. 화면에는 완주 횟수나 실제 Trial 결과를 제시하지 않는다. S84에서는 검토 의견을 받아 전체 픽셀 복사를 행별 집계로 바꾸는 교육용 예시를 짚는다.

기준판 `2d9a8ad`와 비교한 통합본 113장의 렌더에서 변경 화면은 S83과 S112(찾아보기 제목) 두 장이다. 통합본, ACT4 20장, ACT5 16장을 1920×1080으로 렌더해 해당 장의 픽셀 일치, 편집 가능한 텍스트·흐름선, 글자와 화살표의 여백을 확인했다. 여덟 단계·산출물, 분기 표시와 Notes를 대조했다. 전체 389분, ACT4 85분, S83 강의 1분·사례 4분을 유지한다. 113개 Notes의 19개 필드와 세 PPT의 내장 Notes 149개를 확인했다. Windows 발표 PC·교육장 투사·실측 리허설은 미검증이다.
