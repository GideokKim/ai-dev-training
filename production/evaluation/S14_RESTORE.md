# S14 이전 화면 복원

Decision: DEC-0109. Date:2026-10-27. Baseline:`8c6760e`.
Visual reference:`ea74a74`의 S14.

사용자 요청에 따라 S14 전체 화면을 S15 삭제 전 모습으로 복원했다. 추가했던 요청
작성 문장을 제거하고 파일/구현/테스트와 원하는 결과/허용 범위/완료 수용의 원래
글자 크기·위치 및 “Agent는 제안하고, 사람은 최종 선택·승인한다”를 되돌렸다.
Source overlay에서도 같은 수정을 제거했다. S14 Notes는 이전 역할 설명과 일치시켰다.

기존 S15 삭제, 이후 번호,119장·417분과 Q&A3분은 유지한다. S14는 설명2분 뒤
Q&A3분이며 ACT1 제목 S15로 이동한다. 화면에 요청 작성 연결 문장을 다시 넣지 않는다.
다른118장, 원래 근거·그림·표·차트·워크북은 그대로다. 다른5개 ACT 파일도 같다.

통합119장과 ACT0 14장을 최종 파일에서 렌더링했다. S14는 원래 XML과 픽셀이 같고,
나머지118장은 직전 화면과 픽셀이 같다. Full/ACT0 14개 화면과133개 내장 Notes를
대조했다.119개 Notes는19필드이며 S14의 발표 흐름·전환·Fallback만 정렬했다.
모든 장별 시간·Mode·Claim/Evidence 필드와44개 정적 참조는 유지한다.

Windows·제품/계정·교육장·실측 리허설은 UNVERIFIED다. 로컬 글꼴은 기존과 같이
Malgun Gothic/Consolas를 Apple SD Gothic Neo/Menlo로 대체했다. Demo 저장소·Sites·
발표 묶음은 변경하지 않았다.
