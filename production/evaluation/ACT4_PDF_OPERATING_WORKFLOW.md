## S91 · 상태 파일로 작업 인계 · DEC-0164

왼쪽의 검토 의견, 가운데의 `state.md`, 오른쪽의 다음 실행을 따라간다. 파일 속 체크리스트에는 S90의 행별 집계 변경에서 **출력 6개 비교**가 끝났고 **최대 할당량 측정**이 남았다고 적었다. 다음 실행은 미완료 항목을 읽고 같은 입력으로 기준판과 변경안의 최대 할당량을 비교한다. 문서는 교육용 예시이며 실제 상태 파일을 생성하거나 측정값을 확인한 결과로 제시하지 않는다.

기준판 `dbd25f1`과 통합본 113장·ACT4 20장의 렌더 및 내장 Notes를 대조했다. S91을 제외한 112개 화면은 원본과 픽셀이 일치한다. S91의 문서 윤곽, 완료·미완료 구분, 다음 실행으로 가는 방향과 텍스트 여백을 확인했다. S91은 강의 1분·사례 2분, 전체는 113장·386분이다. 교육장 투사와 실측 리허설은 별도 확인 항목이다. [S91 화면](../preview/full/S91.png) · [ACT4 Notes](../notes/ACT_4_NOTES.md)

## S95 · 병합 전 사람의 검증 · DEC-0162

S94에서는 작업이 한도에 걸려 멈출 때 사람이 이어받는다. S95는 한도를 지키고 AI가 밝기 통계 수정을 완료했다고 보고했을 때를 다룬다. AI가 제출한 변경안과 검사 기록을 사람이 직접 읽고, 기준판과 출력 6개가 같은지, 같은 입력에서 최대 할당량이 줄었는지 확인한다. 두 조건이 확인되면 사람이 병합을 승인하고, 측정 근거가 부족하면 AI가 보완한 결과를 다시 검증한다. S96은 이 판단을 각자의 팀 업무에 적용하는 질문이다.

교육용 역할 아이콘을 재사용하고, 제출·승인은 오른쪽으로, 재측정은 AI 쪽으로 돌아가는 화살표로 표현했다. 시간은 강의 2분이다. 이 예시는 측정 성공이나 실제 승인 기록을 추가하지 않는다.

기준판 `78687c8`과 비교해 전체 113장 중 S95만 화면이 바뀌었다. 통합본과 ACT4의 133개 렌더와 내장 Notes를 대조했다. S94 Notes의 마지막 질문은 변경된 S95를 예고한다. 실제 발표 PC·교육장 리허설은 미검증이다. [S95 화면](../preview/full/S95.png) · [ACT4 Notes](../notes/ACT_4_NOTES.md) · [ACT4 PPT](../ACT_4.pptx)

## 이전 S90 · DEC-0161

S91의 상태 파일에는 이미 확인한 출력과 아직 필요한 측정이 구분되어 남는다. 모델명과 로고는 역할 식별용으로 사용했다. 이 장은 실제 모델 간 대화나 측정 결과를 재현한 화면이 아니다. [이미지 출처](../../assets/slide-illustrations/model-handoff/README.md)

기준판 `6184d77`과 대조했다. 통합본 113장과 ACT4 20장의 내장 Notes가 각 Markdown 본문과 일치한다. 통합본에서 S90만 화면이 달라졌으며, ACT4와 통합본의 S90이 같은 픽셀로 렌더됐다. 양쪽 로고와 모델명, 두 방향의 화살표 및 문구를 확인했다. S90은 강의 1분·사례 3분, 전체는 113장·386분이다. 실제 모델 호출·현장 리허설은 수행하지 않았다.
