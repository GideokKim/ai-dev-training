# 점심 전 요청에서 첫 수정안 검토까지 · DEC-0149

S79는 S77의 질문과 “응, 시작해.”라는 답으로 첫 구현이 시작되는 교육용 상황이다. 검토에서 전체 픽셀 복사가 발견되자 개발자가 다시 수정을 요청한다. S80은 같은 검토 순간을 루프로 다시 보여준다. 동일한 지적이 구현으로 이어지며 수정안은 처음의 기준으로 재검토된다.

S81은 점심 전 요청의 두 문장과 이 사례의 완료 조건을 구분한다. S82는 같은 첫 구현의 목록 생성식을 확대한다. 실제 성능이나 반복 실행 결과를 추가하지 않았다.
