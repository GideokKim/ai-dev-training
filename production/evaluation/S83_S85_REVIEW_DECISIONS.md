# ACT4 · 검토 지적을 다음 구현과 측정에 연결하기

DEC-0150을 기준으로 S82에서 발견한 목록 생성식, S83에서 채택한 지적, S84의 변경, S85의 재검토 판단을 대조했다. 이 예시는 별도 실행 결과가 없는 교육용 재구성이다.

| 화면 | 확인한 내용 |
|---|---|
| S83 | 목록 생성식으로 확인한 전체 픽셀 복사를 지적 R1로 표시한다. 명세와 충돌하는 제안은 기각하고 실행시간 주장은 별도 측정으로 넘긴다. |
| S84 | S83과 지적 카드의 문구·색·위치가 같다. 첫 후보의 전체 픽셀 목록과, 행마다 최소·최대는 갱신하고 합은 누적하는 다음 후보를 나란히 보여준다. |
| S85 | 실행시간 기록이 없으면 같은 후보를 기준판과 동일한 입력·환경에서 먼저 측정한다. 세 기준이 모두 충족되면 근거와 후보를 제출하고, 확인된 위반은 재수정으로 돌린다. 측정이 불가능하거나 정한 한도에 도달하면 미완료 상태와 이유를 사람에게 넘긴다. |
| S112 | ‘검증과 개선’ 찾아보기에 S83·S85의 새 제목이 표시되고 두 장의 팁 배지도 유지된다. |
