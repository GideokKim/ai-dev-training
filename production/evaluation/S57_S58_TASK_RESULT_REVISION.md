## S57 변경과 읽는 순서

1. 제목과 작업 문장: 이미지의 최소·최대·평균 밝기를 구하고 기존 결과를 유지한다.
2. 기존 구현: 행별 픽셀을 하나의 큰 임시 리스트로 모아 계산하는 구조를 본다.
3. 변경 후보: 큰 임시 리스트 없이 계산한 수동 반복과 행별 내장 연산을 비교한다.
4. 선택: 두 후보의 결과와 할당량을 확인한 뒤, 더 빠른 행 단위 연산을 선택한다.

칸과 연결선은 편집 가능한 구현 도식이다. 실제 입력 이미지·픽셀 값·화면
캡처나 측정 비율로 제시하지 않는다. 두 후보 사이의 시간 방향만 표시하며
정확한 후보 수치는 원자료에 보존한다. 색과 제외/선택 문구를 함께 사용한다.
