## 수정 범위와 보존

- 실제 입력 문장을 담은 짧은 요청, 비교 요청, 기법별 예시, Skill/Agent 제작·사용, 피드백 재요청을 같은 문법으로 맞췄다. AGENTS.md/SKILL.md/state.md·코드·로그·답변·결과·청중 질문은 입력창으로 바꾸지 않았다.
- 기존 ChatGPT/Codex/VS Code 도식은 내부 내용과 이미지 원본을 보존하고 창 외형을 맞췄다. 공통 외형은 현재 제품 실행을 새로 입증하지 않으며 CLI/재구성/교육용 가정의 구분은 Notes에 유지한다. 화면에 새 면책 문구를 추가하지 않았다.
- 요청 원문·기존 강조·번호 대응을 보존했다. 제목 막대가 본문을 가리지 않도록 필요한 여백만 조정했다. S71 사용 요청은 한 줄로 정렬하고, S39는 이동한 문장과 겹치던 기존 구분선3개를 제거했다.
- 111장·372분, 각 ID·제목·ACT·Section·Beat·핵심 역할·시간·Mode·근거·Claim Boundary를 유지했다. 표는 S54/S81/S85, 차트는 S69에 그대로 있다.
