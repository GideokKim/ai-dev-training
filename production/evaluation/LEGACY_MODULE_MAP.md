## 표시의 의미

M 연계는 현재 화면에서 직접 가르치는 원모듈의 개별 내용 또는 명시적인 공통 원칙의 연결이다. 원모듈 전체 이수·완전 이관·원사례 구현·성과 보증을 뜻하지 않는다. 직접 교수 연결이 없는 현행 확장은 신규 확장으로 표시한다.

- 화면 표시의 유일한 데이터 파일은 `production/source/presentation-revision/legacy-module-map.json`이다.
- `direct`: 실제 화면이 원모듈의 의미 있는 개별 학습 내용을 직접 설명하거나 구체 사례로 보여준다. 전체 모듈 반영을 뜻하지 않는다.
- `principle`: 원모듈과 명시적인 공통 원칙을 가르치지만 업무 범위·사례·방법이 다르거나 여러 수준의 연결이 섞인다.
- `new_extension`: 직접 교수 내용 연결이 충분하지 않은 현행 확장이다. `modules`는 빈 배열이며 라벨은 `M 연계 · 신규 확장`이다.
- 이름·문서 위치·출처 인용만으로 모듈을 배정하지 않는다. Notes 전용 내용은 화면 라벨의 근거로 세지 않는다.

- **S85–86:** 구성 선택과 사람의 책임이라는 공통 원칙만 연결한다. 자동화 후보 분류·TCO·ICE·ADR·양산 승인 절차를 이수했다고 표시하지 않는다.
