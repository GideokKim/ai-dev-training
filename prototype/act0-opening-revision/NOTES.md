## S01 — AI에게 지금 무엇을 맡기고 있는가?

Slide ID: S01

Working Title: AI에게 지금 무엇을 맡기고 있는가?

ACT / Section: ACT 0 / 0A

Allocated Time: 5 minutes

Mode Split: Lecture 1 minute + Reflection 4 minutes

Primary Message: 자기 AI 활용을 평가하지 않고, 현재 맡기는 업무 범위를 돌아본다.

Opening Question: “나는 지금 AI에게 무엇을 맡기고 있는가?” 화면의 한 줄 안내처럼 최근 AI에 맡긴 일 하나를 떠올리게 한다.

Speaker Flow: 1. **OPEN (0:00–0:15 / Lecture):** 기존 제목과 “최근 AI에 맡긴 일 하나를 떠올려보세요”를 읽는다. 사용 수준을 평가하는 자리가 아니며 익숙한 경험 하나면 충분하다고 말한다.
2. **THREE CASES (0:15–0:45 / Lecture):** 같은 인물이 등장하는 세 장면을 각각 약 10초씩 가리킨다. “설명받기”에서는 코드 설명을 질문하는 장면, “조사맡기기”에서는 파일과 돋보기로 필요한 근거를 찾는 장면, “결과확인”에서는 변경 코드와 확인 근거를 함께 살피는 장면을 짧게 짚는다. 세 장면은 경험의 예시이며 서열이나 필수 발전 단계가 아니다.
3. **INVITE (0:45–1:00 / Lecture):** 이 중 최근 자신의 경험과 가까운 일 하나만 조용히 떠올리면 된다고 안내한다. Prompt·Context·Harness·Loop의 이름이나 성숙도 설명을 덧붙이지 않는다.
4. **REFLECTION (1:00–5:00):** 네 분의 개인 생각 시간을 보존한다. 응답·기록·공유·실천 약속을 요구하지 않고 예시 설명을 계속하지 않는다.

Evidence / Source: BEAT-001, CLM-0001, CLM-0002. TEACHING_MODEL. 삽화: `prototype/act0-opening-revision/assets/S01-cases.png`, image_gen으로 만든 동일 인물의 세 교육용 장면이다. 실제 제품 화면·회사 현장·관찰된 작업 결과가 아니다.

Claim Boundary: 특정 AI 제품의 성능·우열 또는 개인의 숙련도를 평가하지 않는다. 질문과 업무 범위는 교육을 여는 모델이다. 세 그림은 image_gen 교육용 삽화이며 실제 사용 화면이나 관찰 근거가 아니다. 설명·조사·결과 확인을 숙련도 순위 또는 모든 사람이 거쳐야 하는 단계로 제시하지 않는다.

Beginner Explanation: 지금 자주 맡기는 작은 일 하나를 떠올리면 충분하다. 아직 해보지 않은 사용법을 아는 척할 필요는 없다.

Advanced Insight: 서로 다른 출발점을 같은 문제 중심 Story에서 다룬다. 세 장면으로 익숙한 경험을 떠올리게 하며 다음 단계 이름이나 고급 구성요소를 이 장에서 미리 설명하지 않는다.

C++ Vision Bridge: N/A.

Demo Operation: N/A. 삽화 세 장면을 강사가 가리키는 도입이다. 실제 제품 조작·새 Trial·실행 결과 시연이 아니다.

Audience Interaction: Reflection은 개인적인 생각 시간이다. 답변·기록·공유·실천 약속을 요구하지 않는다. 세 사례 중 경험을 발표하거나 자신의 수준을 고르게 하지 않는다.

Transition: 작은 코드나 오류를 질문하는 익숙한 방식부터 인정하며 S02로 간다.

Time Management: Lecture 1분 안에 세 장면을 각각 약 10초씩 짚고 1분에 설명을 멈춘다. Reflection 4분간 침묵을 허용한다. 강사의 예시 해설이나 청중 응답으로 생각 시간을 대체하지 않는다. 5분 배분은 유지하며 실제 발화·운영 시간은 아직 측정하지 않았다.

Fallback: 검토용 정적 PNG `prototype/act0-opening-revision/preview/S01.png`와 같은 질문을 사용한다. 청중 반응이 없어도 기다린 뒤 다음 장으로 간다. 실제 제품 화면이나 개인 경험 발표로 대체하지 않는다.

Validation Status: REVIEW COPY — S01/S02 두 장 검토본용 Notes다. 두 레코드의 PPT 내장 Notes 삽입과 로컬 PNG 대조를 확인했다. 공식 80장 통합본과 발표자 묶음은 수정하지 않는다. Windows PowerPoint·실제 발표 PC 글꼴·교육장 투사·제품/계정·실측 리허설 검증은 수행하지 않았다.

## S02 — 작은 질문에는 Chatbot이 유용하다

Slide ID: S02

Working Title: 작은 질문에는 Chatbot이 유용하다

ACT / Section: ACT 0 / 0B

Allocated Time: 5 minutes

Mode Split: Lecture 5 minutes

Primary Message: 필요한 코드나 오류를 전달해 답을 받는 방식은 작은 질문에서 빠르고 유용할 수 있다.

Opening Question: “이 초기화는 어떤 원소를 만들까?” 작은 코드의 뜻을 묻는 교육용 질문으로 연다.

Speaker Flow: 1. **OPEN (0:00–0:45):** `std::vector<int> values{1, 2, 3, 4};`와 “이 초기화는 어떤 원소를 만들까?”를 보여 준다. 실제 ChatGPT 대화나 컴파일 실행 화면이 아니라 작은 코드 질문을 설명하기 위한 예시라고 알린다.
2. **EXPLAIN (0:45–1:45):** 도식의 원소 1·2·3·4를 차례로 가리키고 원소가 네 개라는 뜻을 확인한다. 도식은 이 코드의 뜻을 설명하며 실행 출력이나 실제 Chatbot 응답을 재현하지 않는다.
3. **FOLLOW THE LOOP (1:45–3:45):** 연결된 세 노드를 각각 약 40초씩 따라간다. 첫 IDE에서 “코드 선택·복사”, Chatbot에서 “붙여넣고 질문”, 마지막 IDE에서 “답 확인·적용”의 관계를 설명한다. 마지막 단계는 답이 원래 코드·요청과 맞는지 확인한 뒤 필요한 부분을 적용하는 교육용 흐름이다. 세 화면 사이의 자동 연동이나 실제 코드 변경·실행 결과를 보여 주는 것이 아니다.
4. **INTERPRET (3:45–4:30):** 필요한 코드와 질문의 범위를 사람이 골라 전달하고 답을 확인한다는 점을 짚는다. 작은 코드 조각의 뜻을 이해하는 데 이런 방식이 유용할 수 있음을 인정한다.
5. **TRANSITION (4:30–5:00):** 질문이 여러 파일과 구현 경로로 커지면 무엇부터 찾아 전달해야 할지 S03의 질문으로 연결한다. 현재 방식을 낡았거나 잘못된 사용법으로 평가하지 않는다.

Evidence / Source: BEAT-001, CLM-0001, CLM-0002. TEACHING_MODEL / CONCEPTUAL. `std::vector<int> values{1, 2, 3, 4};`와 네 원소 1·2·3·4의 도식은 화면 설명용 코드 예시다. IDE → Chatbot → IDE의 세 노드는 강의용 native 도식이며 실제 ChatGPT 응답·제품 UI·컴파일 실행 또는 새 Trial 기록이 아니다.

Claim Boundary: 일반적인 예시이며 특정 제품 기능, 정확도, 성능 또는 다른 방식보다 우월하다는 주장으로 말하지 않는다. C++ 코드와 원소 도식은 교육용 설명이고 실제 컴파일·실행 결과나 ChatGPT 대화가 아니다. IDE의 코드 선택·복사, 대화에 붙여넣고 질문, IDE에서 답 확인·적용은 사람이 연결하는 흐름이며 자동 IDE 연동을 뜻하지 않는다.

Beginner Explanation: 작은 코드 조각을 함께 보여 주고 어떤 원소가 만들어지는지 설명을 받는 것은 자연스러운 시작점이다. 답을 받은 뒤 원래 코드와 맞는지 확인하는 과정도 사람이 맡는다.

Advanced Insight: 흐름에 필요한 Context를 개발자가 직접 선택해 복사한다. 세 노드를 연결해 선택·전달·답 확인의 책임을 보이며 여기서는 그 수고가 항상 문제라고 단정하지 않는다.

C++ Vision Bridge: 설명용 C++ 표준 라이브러리 코드 한 줄을 사용한다. 특정 IDE·컴파일러·Windows 빌드 조건이나 Vision 장비 실행을 가르치는 예시는 아니다.

Demo Operation: N/A. 코드와 네 원소의 도식, 연결된 IDE → Chatbot → IDE native 흐름을 강사가 설명한다. 실제 대화·IDE 자동 연동·컴파일 실행·새 Trial은 없다.

Audience Interaction: Opening question은 생각을 여는 질문이다. 코드 작성·실행·손들기·경험 발표나 답변을 요구하지 않는다.

Transition: 질문이 여러 파일·구현 경로로 커지면 무엇을 먼저 찾아야 하는지 S03에서 묻는다.

Time Management: Lecture 5분을 유지한다. 코드 질문 45초, 네 원소 도식 1분, 연결된 세 노드 2분, 사람이 선택하는 Context 해석 45초, S03 연결 30초로 편성한다. 상세 Prompt 작성법이나 초기화 문법 전반의 강의를 추가하지 않는다. 실제 발화·운영 시간은 아직 측정하지 않았다.

Fallback: 검토용 정적 PNG `prototype/act0-opening-revision/preview/S02.png`의 C++ 코드·원소 도식·연결된 세 노드를 설명한다. 실제 ChatGPT 대화나 즉석 제품 화면으로 대체하지 않는다.
