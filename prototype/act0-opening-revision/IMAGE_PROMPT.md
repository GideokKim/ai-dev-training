+Use case: productivity-visual.
Asset type: a single text-free illustration strip for a Korean developer training PowerPoint.
Primary request: three distinct, equally weighted scenes showing familiar ways a developer works with AI, arranged left to right as a wide 3:1 triptych. These are alternatives, not a maturity ladder.
Scene 1, left third: a developer at a laptop asking about a small piece of code or an error, with a floating speech bubble containing only a few abstract code marks and a small question symbol.
Scene 2, middle third: the same developer investigating related repository files, with a magnifying glass over a small connected cluster of code documents and folders. Show investigation rather than a pile of floating decorations.
Scene 3, right third: the same developer carefully checking a code change against a test/checklist, with two simple code documents and restrained check marks. A human visibly reviews the result.
Style: restrained contemporary editorial line illustration, pale gray-blue fill, dark slate outlines, muted teal accents, subtle soft shading, professional engineering training style. Friendly but not cartoonish. Similar scale and visual complexity across all three scenes.
Composition: exactly three clean separate vignettes centered within equal thirds, ample plain negative space between them, no panels or card borders, no arrows or connectors between scenes, no podium or ranking, no step numbering. Wide landscape 3:1 overall canvas. Keep all elements within the canvas with generous outer padding. The developer should be a small part of each scene; make code explanation, repository investigation and verification visually distinct.
Background: uniform very light cool gray #F4F6F8, matching a light PowerPoint slide.
Text: no words, no labels, no letters, no numbers, no logos, no readable terminal output. Abstract code marks like brackets and question/check symbols are allowed. Captions will be editable PowerPoint text outside the image.
Constraints: this is a teaching illustration, not a screenshot, not a product interface, not evidence of a successful agent run. No bright rainbow colors, no robots, no gradients behind the subjects, no frames, no full slide design.
