# AI 개발자 교육

## 목적

개발자 대상 ChatGPT & Codex 6시간 사내 교육자료를 제작한다.

## 현재 상태

Git 저장소와 기본 디렉터리 구조를 만들고 [기획 원본](plan/MASTER_PLAN.md),
[Coverage Matrix](plan/MASTER_PLAN_COVERAGE.md), STEP 02 Governance 문서인
[Invariants](plan/INVARIANTS.md), [Decision Log](plan/DECISIONS.md),
[Decision Template](plan/DECISION_TEMPLATE.md)을 작성했다. 교육 콘텐츠와
최종 Demo 운영 자료는 아직 작성하지 않았다. STEP 07에서 별도 형제 저장소
[`ai-dev-training-demo`](../ai-dev-training-demo)를 만들고 STATE-00 기준 구현을
검증했다. TRIAL-001/002는 격리된 Codex CLI 환경에서 수행했고, crop 경계 수정을
`STATE-00-FIXED` commit/tag로 기록했다. Codex Desktop 리허설은 아직 남아 있으며,
다음 상태를 위한 반복 Project Context와 `AGENTS.md` 성공 조건을 계획했다.
`STATE-01`과 `AGENTS.md`는 아직 만들지 않았다. Demo 저장소에는 원격이 없어
고정 상태를 push하지 않았다.
