# AI 개발자 교육

## 목적

개발자 대상 ChatGPT & Codex 6시간 사내 교육자료를 제작한다.
기획 기준은 [MASTER_PLAN](plan/MASTER_PLAN.md), 변경 이력은
[DECISIONS](plan/DECISIONS.md)를 따른다.

## 현재 상태

80장 통합 PPT, ACT 0–5 PPT, 발표자 Notes와 로컬 렌더 검토가 완료됐다.
현재 발표자료는 `adba817` / DEC-0033이다. S07·S14·S18·S19 본문과 Notes 네 장을
보강하고 80장 하단에 M 연계 표시를 넣었다. M 표시는 관련 내용·원칙의 연결이며
원 모듈 전체 충족을 뜻하지 않는다. 80장·360분·Mode를 유지하고 2순위 보강은 보류했다.
기존 DEC-0032의 연결 흐름 개선은 보존했다. 발표자 묶음은 이 후보로 재생성했고
생성·검증 결과는 패키지 결과에서 확인한다. 실환경·리허설은 아직 UNVERIFIED다.

- [발표자용 자료 묶음](delivery/README.md)
- [현재 전달 안내와 후보 해시](production/evaluation/FINAL_HANDOFF.md)
- [예상 질문·답변](production/presenter/EXPECTED_QA.md)
- [사용자 실환경·리허설 체크리스트](production/evaluation/USER_VALIDATION_CHECKLIST.md)

기본 시연은 기록에 근거한 정적 PPT/PNG다. 현재 계정·제품의 Live 동작으로
표현하지 않는다. 교육은 순수 360분이며 휴식은 별도다.

Demo는 별도 형제 저장소 `ai-dev-training-demo`에서 관리한다. 기존 State/tag를
유지하며 원격은 구성하지 않았다. 이번 전달 준비에서는 Demo를 변경하지 않는다.
초기 구조와 제작 과정의 이전 상태는 Git 및 기획·평가 문서에 보존한다.
