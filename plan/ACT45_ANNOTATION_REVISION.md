## 시각적 수정

- S93: Agent가 허용된 폴더에서 코드 수정·테스트를 하고 승인된 연결만 사용하는 영역과, 관련 없는 파일·비밀 키·배포 권한에 접근하지 않는 영역을 대비한다. 접근 경계에서 선을 끊어 금지를 표시한다. Worktree는 파일 분리이고 권한 제한은 별도 실행 통제라는 기존 한계를 유지한다. 실제 보안 설정이나 차단 시험의 결과가 아니다.
- 현재 S105: 같은 작업·입력에서 두 후보 구성으로 갈라지는 선과 동일 평가 기준으로 모이는 선에 둥근 꺾임을 사용한다. 화살촉은 후보와 평가 프레임의 도착 지점에만 둔다. 실제 평가 결과·PASS/FAIL·측정값은 추가하지 않는다.
- 현재 S106: 머리말을 “ACT 5 · 문제 하나 고르기”로 바꾼다. 기존 A–E와 다음 행동 장의 정렬, 근거·내용·시간은 보존한다. Section5B와 기존 선택지의 출처를 새로 정의하지 않는다.

## 연결

S95는 AI 제출물의 사람 검증을 마친 뒤 “이 완료 근거와 중단 조건을 Goal 요청에 어떻게 담을까?”로 현재 S96에 바로 연결한다. 삭제한 개인 성찰·Q&A를 앞뒤 Notes에 흡수하거나 이미 수행했다고 전제하지 않는다. 현재 S97 ACT5 표지는 Goal 요청과 검증 근거를 받아 업무 구성의 재평가로 이어진다.
