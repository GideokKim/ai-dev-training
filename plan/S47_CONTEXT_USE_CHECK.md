## 현재 설계 — DEC-0124 (2026-11-02)

제목: “지침을 놓쳐도 답은 그럴듯할 수 있다”.
S46의 제한된 정보 활용 연구를 받아, 빠진 지침과 그럴듯한 오답을 경계하는 장으로 정리한다.
기존 명세/너비6/crop 2 5 요청은 유지한다. 오른쪽은 “그럴듯한 오답 예시”다.
명세대로라는 단정 아래 열2·3·4·5, 폭4를 제시하고5와4만 빨간색으로 강조한다.
“놓친 조건: 끝 열 제외”와 올바른 기준 열2·3·4/폭3을 함께 보여준다.
하단: “그럴듯한 답도, 지침·근거와 대조한다.”

지침 누락은 요구조건 미반영, 할루시네이션은 그럴듯하지만 사실과 다른 주장으로 구분한다.
이 장은 두 문제를 함께 주의하는 구성이지 같은 현상이나 단일 인과로 규정하는 장이 아니다.
오답은 교육용 가정이며 실제 Agent 응답·Trial·테스트·현재 제품의 관찰이 아니다.
S46 연구가 이 crop 실패나 현재 Codex의 할루시네이션을 입증했다고 설명하지 않는다.
[근거 범위](../references/research/context-use-and-plausible-errors.md)를 따른다.

S46의 입력 정보 활용 질문→S47의 지침/근거 대조 주의→S48 상세 명세 위치 안내를 유지한다.
S46/S48 화면·Notes와 다른119장은 바꾸지 않는다. S47 Lecture4분, 전체120장·417분,
ACT2 22장·90분,19Notes 필드·기존 T03-C와12Templates/28Variants를 유지한다.
기존 코드 탐색 질문·RepoQA·정답 예시의 설계 이유는 Notes/아래 기록에 보존한다.
Windows·교육장·현재 제품/계정·실측 리허설은 UNVERIFIED다.

## 보존된 DEC-0123 설계

Decision: DEC-0123. Date:2026-11-02.

S47의 제목은 “내가 준 Context를 답에 제대로 반영했을까?”다.
제공한 조건과 답의 결론을 직접 대조하는 한 가지 메시지에 집중한다.

## 화면

왼쪽에는 Context와 현재 요청을 구분한다. Context는 crop 시작 열 포함/끝 열 제외다.
요청은 너비6인 이미지의 crop 2 5에 포함되는 열과 출력 폭이다.
오른쪽에는 “답변 예시”라는 제목 아래 원본 열 번호2·3·4/제외되는5/폭3을 보여준다.
명세의 끝 제외와 답의5 제외를 같은 색으로 연결하고, 폭은5−2=3과 대조한다.
하단은 “제공한 조건과 답의 결론을 직접 대조한다.” 한 문장만 둔다.
Native text/shape와 기존 T03-C, 색·폰트·M 연계·Safe Margin을 유지한다.

## 연결

- S46: 정보를 넣었다는 사실과 답에서 활용됐는지의 질문을 구분한다.
- S47: 제공한 조건을 답의 범위·계산에 대조한다.
- S48: 이런 상세 명세를 필요한 작업에서 찾게 할 위치 안내를 설계한다.

S46의 마지막 Cue와 S48의 도입만 맞춘다. 두 장의 화면·연구 설명·Routing 구조는
바꾸지 않는다. 코드 탐색 세 질문과 RepoQA는 정규4분 화면에서 빼고 Notes의 선택 참고로
보존한다. ACT0의 crop 명세나 ACT1의 테스트 강의를 다시 만드는 장이 아니다.

## 근거 범위

명세 출처는 STATE-03 docs/image-contracts.md Crop 절이다. 너비6/crop 2 5와 답변은
해당 명세로 구성한 교육용 예시이며 실제 요청·응답 캡처나 TRIAL-005A/B 기록이 아니다.
새 Trial·테스트·현재 제품 검증을 실행하지 않는다. 모델 내부 활용의 인과나 토큰/성능
효과를 입증했다고 주장하지 않는다. 기존 연구·코드·State/Trial 근거는 변경하지 않는다.
