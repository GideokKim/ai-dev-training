# ACT0 전환 정리 — 이전 S15 삭제

Decision: DEC-0108. Date:2026-10-27. Baseline:`ea74a74`.

사용자가 이전 S15의 삭제와 S14→ACT1 연결 개선을 승인했다. 제조 검사 파이프라인의
가상 전환 장만 제거한다. 앞서 확정한 ACT0 조사·환경 제한·정보 수집·제품 UI·사람의
최종 판단과 ACT1의 기존 모호한 요청→구체화·실제 수정·검증 사례는 유지한다.

## 연결

S14의 파일/구현/테스트를 함께 보는 역할과 원하는 결과/허용 범위/완료 수용을 사람이
최종 정하는 역할을 유지한다. 기존 “Agent는 제안하고, 사람은 최종 선택·승인한다”를
보존하고 “결정한 목표·조건·완료 기준을 요청에 담는다”를 마지막 핵심 문장으로 둔다.
ACT0 Q&A를 마친 후 새 S15 제목 “Prompt를 작업 명세로 만들기”, 새 S16의
“filter 성능 개선해줘”로 이어간다. 새 S17의 crop 요청으로 바뀌는 예시는 이번 범위에서
재설계하지 않는다. 삭제한 파이프라인을 계속 설명하거나 청중에게 새 작업 선택을 요구하지 않는다.

## 번호와 시간

120→119. 이전 S01–S14는 유지하고 이전 S16–S120은 S15–S119가 된다.
이전 S15의6분 중 Q&A3분은 S14에 남기고 Transition3분은 줄인다.
S14는 Lecture2+Q&A3=5분, ACT0는14장·42분, 전체119장·417분이다.
ACT1 이후의 개별 시간/Mode는 유지한다. 전체 Mode는 Lecture186/Demo49/Case105/
Reflection22/Transition23/Q&A32분이다. 장수14/22/22/26/20/15,
ACT 시간42/64/90/96/85/40분이다. [번호 이행](SLIDE_ID_MIGRATION_119.md)을 따른다.

## 근거와 이력

Story Beat·Demo·Trial·State·연구 Claim ID와 기존 관찰·해석·미검증 범위는 유지한다.
이전 S15의 가상 검사 파이프라인은 현재 발표 순서에서 제외한다. DEC-0037과 과거
제작/검증 기록은 당시 번호로 보존한다. Source의 이전 판본 factory·설정·asset 파일명과
Notes의 원문 출처는 원래 식별자를 유지하고 현재 기록·화면/참조/Preview 경로만 정렬한다.

Full 및6개 ACT PPTX에서 같은 번호·Notes를 사용한다. Native 표는 S53/S65,
Native 차트는 S69/S96이다. 기존 도표·그림·워크북은 보존한다. 현재 팁 찾아보기는
S116–S118이며 실제 팁 내용은 변하지 않는다. 웹·발표 묶음·Demo 저장소는 변경하지 않는다.

## 검토

최종119장과6개 ACT의119장을 모두 렌더링한다. S13→S14→S15→S16 연결과
S14 가독성을 직접 확인하고, 나머지 장은 번호·현재 참조 외 변화가 없는지 대조한다.
Notes119개/19필드, 장별 시간·Mode·Claim/Trial·현재 링크·Fallback 파일을 검증한다.
Windows·제품/계정·교육장·리허설은 실제 확인 전까지 UNVERIFIED다.
