## 화면과 역할

현재 S59 한 장을 승인된 역할 비교로 바꾼다. 제목은 “프로젝트 기준과 작업 절차는 역할이 다르다”.
상단 요청은 “normalize 성능을 조사해줘.” 하나로 고정한다. 교육용 요약이며 실제 Prompt 전문이 아니다.

| 비교 축 | Project Context | Workflow |
|---|---|---|
| 질문 | 무엇을 참고하고 지켜야 할까? | 어떤 순서로 진행할까? |
| 그림 | AGENTS.md에 담긴 프로젝트 기준·안내 | 번호와 연결선이 있는3단계 작업 레일 |
| 내용 | 기존 이미지 명세 보존 / 테스트 명령의 위치 / 성능 측정 기준 | 변경 전 측정 / 조사·계획·변경 판단 / 테스트·동일 조건 비교 |
| 배치 안내 | 여러 작업의 기본 안내 | SKILL.md 후보, 필요한 작업에 재사용 |

같은 명령을 어디서 확인하는지와 어떤 시점에 무슨 판단에 쓰는지를 구분한다.
세부적인 전/후 테스트 목적은 기존 S62에서 설명하므로 이 장에서 반복하지 않는다.
하단 질문은 “이 작업 순서를 다음 요청에도 매번 다시 적어야 할까요?”다.
화면 하단에 “역할에 따른 배치 예 · AGENTS.md에도 절차를 둘 수 있음”을 남긴다.
문서는 펼쳐 참고하는 형태, Workflow는 진행 순서가 보이는 형태로 대비한다.
두 영역 사이에 진화/대체 화살표를 넣지 않는다. native 편집 가능한 문서·레일·요청을 사용한다.

## 개념·제품 경계

여기서 Project Context는 작업에서 참고할 프로젝트 기준/안내를 뜻한다.
모델 입력 전체라는 넓은 Context에는 Workflow 지침도 들어갈 수 있다.
AGENTS.md에는 절차를 쓸 수 있고 Skill에는 관련 지식과 참고 자료를 담을 수 있다.
두 파일의 내용이 상호 배타적인 제품 규칙이라고 설명하지 않는다.
공통 기준/안내와 특정 작업에 재사용할 방법을 어디에 유지할지 판단하는 교육용 배치 기준이다.

공식 근거(2026-11-02 확인):
- [OpenAI AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md): 프로젝트 지침·작업 기준. 실행을 요구하는 규칙도 예시에 포함한다.
- [OpenAI Build skills](https://learn.chatgpt.com/docs/build-skills): 재사용 Workflow를 지침·참고 자료·선택적 스크립트로 구성한다.

S59의 SKILL.md는 후보 표시이며 새 파일 생성·Skill 호출·성공 관찰을 뜻하지 않는다.
현재 제품 가용성, 자동 지침 준수, Skill 우월성·토큰 절약·Harness 단독 효과를 추가로 주장하지 않는다.
