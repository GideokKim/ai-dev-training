# Goal 실무 적용 팁과 ACT4→ACT5 연결

Decision: DEC-0098. Approved2026-10-25. Baseline:`4615e0d`.

## 범위와 시간

116장·410분(6시간50분). ACT4 S82–S101은20장·85분, ACT5는 S102–S116의15장·40분이다. ACT 장수14/22/19/26/20/15와 시간43/64/82/96/85/40분. Mode Lecture176/Demo51/Case103/Reflection22/Transition26/Q&A32분이다.

기존114장을 모두 유지한다. 추가 S99/S100에 Lecture2분씩만 더한다. 이전 ACT4의
성찰 S99는 S101, ACT5 제목 S100은 S102, 본문 S101–S114는 S103–S116이다.
실무 팁21개와 마지막 찾아보기 S113–S115를 유지하며 ACT별 중간 요약은 추가하지 않는다.

## 추가 두 장의 역할

| Slide | 역할 | 화면에서 보일 내용 | 경계 |
|---|---|---|---|
| S99 | Goal의 지속 목표·계속 수행 | /goal 설정과 작업→근거 확인→다음 판단, 미충족 시 되돌림 | 공식 안내 각색, 실제 UI·실행 캡처 아님 |
| S100 | 완료를 확인할 Goal 요청 | 임시 할당 감소, 출력 보존, 같은 입력의 검사·측정, 회귀/검증 불가/반복 실패 보고 | 교육용 요청, 실행·측정·자동 검토 결과 없음 |

기능을 켜면 다른 모델 검토자가 자동 배정된다고 설명하지 않는다. 구현 모델과 검토 모델의
역할 선택, 독립적인 도구 근거와 최종 수용 책임을 별도로 설명한다. 예산·막힘 등의 중단과
목표 충족 완료를 구분하며 실제 사내 기능 노출·계정·제품 표면은 미검증으로 둔다.

## ACT5 초반 연결 검토와 수정 범위

| Current slide | 확인한 연결 문제 | 정렬한 역할 |
|---|---|---|
| S101 | Goal 뒤에도 모두 직접 구현해야 하는지 질문이 남음 | 제품 기능 활용과 필요한 검증·검토의 조합을 성찰 |
| S102 | 제목만으로 방향을 알 수 있으며 재설계 불필요 | 승인 제목·부제·1분 유지, Notes로 전환 연결 |
| S103 | 더해 온 대응의 회고만 강조되면 Goal과 덜어내기 연결이 약함 | 대응 선택 지도로 회수, Loop의 문제를 다음 수정의 단절로 명확화 |
| S104 | Goal과 다중 모델 루프도 실제 Demo에 있었던 것으로 오해 가능 | 실제 일곱 State·세 변경은 보존, Goal/다중 모델 실행 검증과 분리 |
| S105 | 과거 Subagent/Memory 보류를 현재 모든 과제의 처방으로 오해 가능 | 실제 과거 작업의 의존관계·지식 출처라는 범위만 Notes에서 강조 |
| S106 | 제품 완료 보고와 사람이 수용하는 판단의 연결이 약함 | Goal 완료 보고 뒤에도 네 수용 질문과 근거 확인 유지 |
| S107→S108 | 작업 환경 설계에서 플랫폼 변화/통합 사례로 갑자기 이동할 수 있음 | Goal처럼 플랫폼이 제공하는 역할을 회수한 뒤 별도 Anthropic 사례로 넘김 |

ACT5 전체를 다시 설계하거나 시간을 줄이지 않는다. 이후 조합·통합·제거와 같은 대표 작업의
회귀 확인, 개인 다음 행동·마지막 찾아보기를 보존한다. Goal이 있으면 자체 실행 체계를 모두
제거할 수 있다고 일반화하지 않으며, 실제 요구·도구·모델 역할·운영 제약으로 판단한다.
