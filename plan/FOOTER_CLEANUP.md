# 청중용 하단 표기 정리

Decision: DEC-0103. 승인일:2026-10-26. 기준 판본:`aaed341` /117장·412분.

## 승인 범위

전체 하단 정리 검토안에 대한 사용자의 수정 승인을 적용한다. 본문·그림·수치·화살표·표·차트·장별 시간/Mode·근거의 의미는 그대로다. 화면 밖으로 옮긴 상세는 Notes와 원본 기록에 보존한다.

## 화면 규칙

- 제작 방법·생성 도구·“무엇을 보여주는 장”이라는 해설·내부 추적 코드·버전·문서 확인일·발표 운영 지시는 화면에서 삭제/Notes로 이동한다.
- 실제/가상, 측정 지표·조건, 연구명·연도·과제와 중요한 해석 한계는 자연어로 짧게 남긴다.
- 실제 실행처럼 보일 수 있는 UI는 “사용 예시/메뉴 예시”로 구분하며 실행 증거로 바꾸지 않는다.
- 학습 내용 자체인 검증·중단·책임·요구사항 보존의 원칙은 유지한다.
- 기존 M1–M9 표시는 전117장에 유지한다.6개 ACT 제목의 과정명도 유지한다.
-111개 일반 장의 기존222행을92행으로 축약한다.26개 일반 장은 출처/제작 설명 행을 비운다. 본문 레이아웃을 재설계하거나 늘리지 않는다.
- 하단은 기존14–15pt 글자 계층과 최대2행을 유지한다. 기존 Evidence 경계선·색 구분·M 연계 위치는 유지한다.
- 상세 출처·가상/관찰/미검증의 범위를 Notes의 기존19필드 안에 보존한다. 새 Notes 필드를 만들지 않는다.
