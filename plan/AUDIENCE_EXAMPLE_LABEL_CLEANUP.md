## 적용 범위

- S36/S37의 지정 두 하단 설명은 전체 객체를 삭제한다. 창 제목은 각각 “작업 요청”, “앞 장과 같은 요청”으로 둔다.
- S21의 실제 발췌·번역 근거는 창 제목과 Notes에 남는다. 다섯 항목은 여전히 해석 주석이며 원문에 Context 문단을 새로 만들지 않는다.
- 요청 본문·수치·도식·이미지·화살표·템플릿·장별 시간·Mode·M 연계는 유지한다. 공통 Mac 창의 형태·위치·글꼴도 유지한다.
- “예시”가 사용법·가정의 내용을 설명하는 경우까지 일괄 삭제하지 않는다. “개념도·실측 아님”, 실제 발췌의 출처와 연구·제품 범위는 이번 교육용 제작 문구 삭제 대상과 구분한다.
- Notes19필드와 Evidence/Claim 문장을 그대로 보존한다. 화면 문구 삭제가 실제 Trial·반복 실행·성능·제품 동작의 새 근거를 만들지 않는다.
- 직전 C++ 비교 반영 DEC-0183과 원래 Python 기록의 분리를 유지한다. ACT0의 별도 흐름 기획은 이 변경에 포함하지 않는다.

남지 않았는지 확인한다. 변경 영역 밖 픽셀, 다른101장 화면, Notes와 근거,
