## 실제 관찰과 교육용 해석

- TRIAL-001:2026-09-28, Codex CLI0.154.0, STATE-00, 읽기 전용 조사. Crop 끝 좌표
  포함 결함을 설명했지만 코드 수정은 없었다. README에도 기존 결함 안내가 있었다.

  환경 오류는 임시 디렉터리 생성 제한이며 Crop/Product 결함의 추가 증거가 아니다.
- S06의 자료 관계와 코드 호출 관계는 Agent의 시간순 접근 기록이 아니다.
- S07은 제한을 관찰한 사례이며 권한 해제·복구·새 상태를 뜻하지 않는다.
- S08/S09는 교육용 종합/가정이다. Chatbot에 자료가 없던 것과 도구의 해결 능력을
  혼동하지 않는다. 로그·권한까지 전달하면 분석 단서도 전달된다.
- S10의 사실 근거는 단일 과거 CLI이며 현재 Desktop·계정·반복성·효율 우위는 미검증.
  Repository의 파일과 도구·권한이 제공하는 실행 조건은 별개다. 목표·검토 책임과
  승인된 도구·계정·자료·접근 범위 확인을 유지한다.
