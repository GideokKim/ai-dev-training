# Memory — ACT5 이동과 작업 간 지식 재사용

Decision: DEC-0133. Date:2026-11-02. Baseline:`ec6a1fb`.

## 승인 범위와 목적

기존119장판 S74의 Context/Memory 설명을 현재 S108과 S110 사이, 새 S109로 옮긴다.
한 작업의 결과를 수용한 뒤 다음 작업에도 쓸 사실을 판단하고 전체 작업 조건 설계로 연결한다.
ACT3는 S73의 Subagent 판단 뒤 S74의 실제 구성 역할, S75의 Harness로 바로 이어진다.
총119장·405분과 기존 장별 배정은 유지한다. Memory4분(Demo2 VISUAL+Case2)을 ACT3에서 ACT5로 옮긴다.

## 새 S109의 학습 역할

제목: “이번에 알아낸 것 중, 다음에도 쓸 것은?”

C++ 프로젝트에서 성능 비교 조건을 확인했다는 교육용 가정을 사용한다.
예시의 재사용 후보는 “Release 빌드·동일 입력으로 비교”다. 이것을 모든 프로젝트의 절대 규칙으로 일반화하지 않는다.
이번 로그·측정값은 날짜가 있는 작업 기록에 두고, 다음에도 쓸 조건은 출처·적용 범위·갱신 조건과 함께 남긴다.
다음 작업에서는 현재 코드·명세·환경과 대조한 뒤 필요한 지식을 Context로 활용한다.
반복 조사를 피하려는 목적과 신뢰성·신선도·재사용성을 설명하며 절감 효과를 측정한 성과로 표현하지 않는다.
특정 Memory 제품·파일 형식·자동 저장·자동 회수·새 지식 저장소를 선택하거나 구현하는 장이 아니다.

## 앞뒤 연결과 중복 경계

- S108: 이번 작업 결과와 남은 위험을 사람이 수용할지 판단한다.
- S109: 그 작업에서 알아낸 내용 중 다음에도 쓸 지식을 출처·조건과 남길지 판단한다.
- S110: 지식·수행 방법·검증과 사람의 책임을 포함해 전체 일할 조건을 정리한다.
- S111–S113: 모델·플랫폼 변화에 따라 실행 체계의 지침·역할·우회 절차를 통합/제거할지 판단한다.

지식의 수명·신선도와 실행 구조의 구성요소 재평가는 역할이 다르다.
ACT3에서 이 장을 미리 설명하거나 기존 Demo의 Memory 후보 감사를 예고하지 않는다.
이전121장판에서 삭제한 S67·S76의 본문 포함 확인/실제 출처 감사·결론·표를 복구하거나 흡수하지 않는다.
기존 원자료와 이미 존재하는 역사 참고 자료는 당시 의미로 보존한다.
