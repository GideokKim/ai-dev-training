# 실무 적용 팁 — 공통 표시와 마지막 통합 찾아보기

Decision:DEC-0088 placement, DEC-0090 numbering. Date:2026-10-25.
현재108장·396분. ACT 제목6장 추가 외 팁 본문17장·공통 배지·분류와 마지막
제목/ID 찾아보기3장의 역할·시간·근거는 동일하다.

## 배치와 근거

팁 설명은 원래 문제·적용 맥락에 둔다. ACT 중간에 목록을 끼워 넣지 않고 마지막
회고 뒤 S105–S107에서 한 번에 안내한 뒤 S108의 기존 Q&A/Closing으로 끝낸다.
공통 배지는 사용 환경/요청 작성/Context 관리/수행 방법/업무 적용/검증·개선을
표시하며 Evidence 등급이 아니다. 일반 개념·연구·실제 결과를 모두 팁으로 분류하지 않는다.
S12의 사내 진입 안내는 대상 제품/계정 확인 전까지 UNVERIFIED다. Prompt 예시·
가상 평가 설계·실제 Trial의 경계를 유지하며 새 Trial/성과는 없다.

## 공통 배지

Native rectangle x780/y44/w320/h34, fill#E8EDF3, 기존line/ink tokens와
Malgun Gothic18px를 유지한다. “실무 적용 팁 · [분류]”는 제목/본문/원본 이미지와
겹치지 않으며 기존 Evidence/claim footer를 보존한다. 마지막3장만
“실무 적용 팁 · 찾아보기”와 “마지막 정리 · 찾아보기 1/3–3/3”를 표시한다.
제목6장에는 팁 배지를 추가하지 않는다.
