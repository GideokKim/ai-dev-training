## 공통 외형

기준은 기존 S41/S66/S71/S77/S96의 macOS풍 요청창이다. 밝은 본문, 연한 회색 제목 막대, 좌측 상단 빨강·노랑·초록 표시, 얇은 테두리와 둥근 모서리를 공유한다. 표준 제목 막대는43px, 작은 창은30/36px를 사용한다. 기존 입력 내용·번호 대응·강조·맥락·도구·관찰 기록을 보존하고, 필요한 곳만 여백과 줄바꿈을 조정한다.

실제 ChatGPT/Codex/VS Code 화면을 연상시키는 기존 UI는 해당 앱의 내용과 구조를 보존하고 창 외형만 맞춘다. Mac 스타일은 공통 발표 문법이며 관찰된 CLI 실행을 현재 Desktop에서 실행한 기록으로 바꾸는 근거가 아니다. 이 구분은 Notes에 유지하고 화면에 새 면책 문구를 추가하지 않는다.

AGENTS.md/SKILL.md/state.md·코드·로그·측정값·Agent 응답은 요청 입력과 다르므로 요청창으로 바꾸지 않는다. 요청을 설명하는 표·제목·요약 참조·작은 기호를 실제 입력창처럼 강제로 바꾸지 않는다. 청중에게 던지는 질문도 그대로 유지한다. 새 Slide/Template 종류/Trial·제품 주장은 추가하지 않는다.
