## 6. 근거와 검증 Gate

- 공식 Quickstart/App 문서를 2026-10-21 확인했다 (SRC-0228/SRC-0229, CLM-0031). ChatGPT dropdown에서 Codex로 들어가는 개발 경로를 뒷받침한다. 좌측 상단 위치는 사용자 UI 명세다. 실제 메뉴 Screenshot·현재 로컬 UI 확인·발표 계정·Windows 실행을 입증하지 않는다.
- 메뉴 재구성은 RESEARCH / TEACHING_MODEL로 구분한다. ChatGPT Work의 파일 접근 가능성까지 부정하는 “오직 Codex만 가능” 단정은 하지 않는다.
