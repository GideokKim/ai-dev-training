# RepoQA — S47 발표자용 선택 참고

Current use: DEC-0105,2026-10-27. Slide S47의 화면과 정규 발표 흐름에서는 제외한다.
기존 연구 검토 SRC-0204/CLM-0015를 보존해, 질문이 있을 때 참고할 관련 연구로 둔다.
새 연구 결과나 제품 검증을 추가한 문서가 아니다.

## 왜 연결했는가

긴 코드 입력을 받을 수 있다는 사실과 기능 설명에 맞는 구현을 정확히 찾는 능력을
구분하는 관련 연구다. S47의 핵심은 실제 업무에서 찾은 위치·요청한 동작·필요한 주변
근거를 확인하는 교육용 기준이다. 논문을 설명하지 않아도 이 실무 질문은 성립한다.

## 연구가 평가한 과제

[RepoQA: Evaluating Long Context Code Understanding](https://arxiv.org/abs/2406.06025),
Liu et al.,2024. 과제명은 Searching Needle Function이다. 자연어 기능 설명과 코드
입력을 제공하고 해당 함수의 코드를 반환하게 한 뒤 정답 함수와 코드 유사도를 비교한다.

기존 SRC-0204 검토에 보존된 조건은50개 저장소·5개 언어·500개 과제이며,
주 평가의 코드 입력은 CodeLlama tokenizer 기준16K다. 모델/언어별 차이를 관찰했다.
이는 전체 Prompt 길이나 현재 Codex의 입력 한도·성능 기준을 뜻하지 않는다.
상세 조건은 [원문](https://arxiv.org/html/2406.06025v1)과
[SRC-0204](../sources/SOURCES.md#src-0204)를 따른다. 서지·과제 연결은2026-10-27
확인한 원문을 따르며 상세 실험 조건의 기존 검토 기록은2026-10-22판을 보존한다.

## 이 연구로 말할 수 없는 것

- S47의 세 업무용 확인 질문의 효과를 검증한 연구가 아니다.
- Agent의 저장소 탐색·수정·도구 호출·테스트 수행 전체를 평가한 결과가 아니다.
- 현재 Codex나 교육용 Routing의 정확도·토큰 절약·성능 개선 근거가 아니다.
- Lost in the Middle의 위치별 현상을 그대로 재현한 연구로 설명하지 않는다.

## 발표 중 선택적으로 답할 때

“코드에서도 설명에 해당하는 함수를 찾는 능력을 별도로 평가한 관련 연구가 있습니다.
이 슬라이드의 세 질문은 그 논문의 채점 기준이 아니라, 업무에서 근거를 확인하기 위한
교육용 기준입니다.” 정도로 한정한다. 정규4분 설명에는 논문 소개를 넣지 않는다.

현재 S46은 입력 정보의 존재/활용 구분, S47은 코드 확인 질문, S48은 필요한 상세 근거에
도달할 경로를 다룬다. 기존 코드 발췌·State/Trial의 관찰 범위는 그대로 유지한다.
