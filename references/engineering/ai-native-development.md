# AI-Native Development

## Research Question

AI-Native Development를 이 교육에서는 어떤 operational usage로 제한해야 하는가?

## Why It Matters

마지막 maturity step을 업계 consensus나 “개발자 대체” 주장으로 오해하지 않게 한다.

## Findings

- **Type: INDUSTRY PRACTICE / Confidence: MEDIUM / Freshness: see Checked date for cited SRC IDs in SOURCES.md / Source: SRC-0136, SRC-0225, SRC-0226, SRC-0227** — AI-native, AI-assisted, SE 3.0, loop engineering are used with different scopes.
- **Type: TEACHING MODEL / Confidence: HIGH / Freshness: see Checked date for cited SRC IDs in SOURCES.md / Source: SRC-0001** — this training uses AI-Native as developers designing agent work environments and feedback systems while retaining goal/judgment/verification/responsibility.
- **Type: ACADEMIC FINDING / Confidence: MEDIUM / Freshness: see Checked date for cited SRC IDs in SOURCES.md / Source: SRC-0213, SRC-0214, SRC-0215, SRC-0216, SRC-0217** — productivity and skill effects vary by tool/task/population.

## What the Evidence Does NOT Prove

AI-Native is not proven as a single universal maturity destination; coding skills are not obsolete.

## Implication for Training

Use Goal / Judgment / Verification / Responsibility as labeled teaching model.

## Demo Implication

AI-Native is a synthesis story concept, not necessarily a live demo.

## Risks / Caveats

External terminology is volatile and vendor-specific.
